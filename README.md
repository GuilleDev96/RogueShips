Un juego por turnos en el que cada partida (la run) es una travesía por un mapa de nodos. En cada
nodo de batalla te enfrentas a una flota enemiga oculta en un tablero con niebla de guerra, como en
el Hundir la flota clásico, pero con habilidades especiales por barco, reliquias que alteran las
reglas, capitanes con rasgos propios, muerte permanente y progreso entre partidas. El motor
del juego es Java puro y Spring Boot actúa como puerta de entrada (API REST) y como almacén
(base de datos).
